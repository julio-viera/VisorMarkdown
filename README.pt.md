## Trabalhe com Markdown

### Edite e visualize

Escreva com números de linha e veja o resultado formatado enquanto digita. Role qualquer um dos painéis para acompanhar o mesmo trecho no outro.

![Edite e visualize](docs/images/editor-preview.png)

### Organize e pesquise

Mantenha vários documentos abertos em abas e navegue entre as correspondências da busca no documento atual.

![Organize e pesquise](docs/images/tabs-search.png)

### Compare documentos

Revise dois arquivos lado a lado, com as alterações destacadas e controles para navegar entre as diferenças.

![Compare documentos](docs/images/document-comparison.png)

### Formate e compartilhe

Escolha GitHub Flavored Markdown, CommonMark ou Markdown Original. Insira uma tabela de exemplo no modo GitHub e exporte para PDF, HTML, texto simples ou Markdown.

![Formate e compartilhe](docs/images/export-options.png)

### Personalize a aparência

Siga o tema do sistema ou escolha o modo claro ou escuro. Ajuste a paleta, as fontes e os tamanhos do texto.

![Personalize a aparência](docs/images/appearance.png)
